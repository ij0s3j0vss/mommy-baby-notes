# 去泰国做试管婴儿的准备和流程

> 更新时间：2026-09-10 (UTC+8)

泰国的试管婴儿率高，试管技术比肩欧美，而医疗费用却远远低于欧美国家，已经是今年来我国患者的首选之地，泰国甚至还有着“东南亚”的称号。那么，去泰国做试管婴儿，我们需要做哪些准备呢？
一、联系方式：
在出国前请您到所使用电话营业厅开通国际漫游，保证您在遇到困难时能随时与相关工作人员取得联系。
二、需要准备的证件：
自从2014年7月，泰国爆出一对华裔夫妇遗弃而来的先天愚型男宝(唐氏综合症)的事件后，泰国政府开始了对试管医疗行为的大力整顿，正规的泰国试管婴儿治疗有了明确的要求，目前到正规的医院进行试管婴儿治疗必须提供以下证件：

1、夫妻双方的护照（有限期必须大于6个月,一般办理为期二个月的自由行签证）

2、结婚证

3、结婚公证书（中英文版本）

4、如果有人说不需要证件，只能说去的不是正规医院，切勿轻信
三、入境手续和注意事项：
1、 持有自由行签证需填写入境卡，入境卡海关回持部分需保留，出境时使用；最好持有时间为两个月之内的可改签往返机票。

2、 落地签的客人需填写以下入境卡和入境表，还需准备与护照相似的2寸照片一张，入境卡海关回持部分需保留，出境时使用；一定要持有15日内往返机票。

3、每人需携带人民币5000元或等值外币，已备海关抽查
四、试管流程：
1、前期身体检查：去泰国之前可以在国内做个激素六项、B超等等相关检查、男方也要做一个分析，只有各方面身体指标达到了，才能进入试管疗程，国内的身体检查报告在泰国也是有效的。

2、制定试管疗程方案：月经第二天去见了医，抽血检查并建立档案，没有问题就可以进行促排了。

3、促排 ：促排就是打排卵针，每天都打，而且是同一时间，也就是说，你第一天促排的时间是在几点，后面几天的促排时间也最好是同一时间，时间上相差绝对不可以超过2个小时。促排时间大概9-12天，具体时间依照每个人的实际状况会不同，这些都是医进行监控的，自己只要听话就行了。打最后一针促排的晚上，医就会安排打夜针（破卵针），36小时之后就可以进行取卵了。

4、取卵：取卵一般是在打夜针后36小时也就是后天的上午安排取卵，男方取精。取卵的过程会有轻微疼痛，不过都是在可以忍受的范围内，可以选择局麻或者全麻。取卵前一晚(午夜12：00)至取卵前是不可食用任何食物以及水。取卵后可食用鸡粥、以及鱼汤。取卵术后休息2-3小时，期间可能会有头痛、恶心、呕吐、小腹会有隐痛，休息后症状可缓解，经医同意，无不适方可回家。如腹部剧痛难忍或有过多流血，要告知医，必须随时急诊就诊。

5、体外受精与胚胎移植：因为去泰国做试管的大都选择第三代试管技术，可以进行胚胎的检测筛查，如果选择做CGH检测，那么在胚胎培育的第三天就可以进行检测了（两天左右出结果），如果胚胎发育良好且母体身体状况也很好的话，在胚胎培育的第五条就可以进行胚胎移植了。如果选择NGS检测，那么就要在胚胎培育的第五天进行检测（一周左右出结果），而移植就要等到下一个周期才可以。NGS是现在最新的检测技术，价格与CGH并无差别，选择的人更多一些。

6、验孕：胚胎移植后第十天可以进行抽血验孕，可以选择在泰国验孕后回国，也可回国后验孕，不过建议还是在泰国验孕后回来，毕竟胚胎移植后也建议卧床休息4-5天，不如在多等上五天等结果了，验孕，保持着愉快的心情，遵循医建议安胎；验孕失败，也要保持积极地心态，根据医的建议准备下次的治疗。

7、注意：泰国的医院都是预约制。去泰国之前建议提前预约好，一般的医院都有网址，可以用英文邮件进行预约，英文好的可以直接电话预约。

泰国试管婴儿率高，医疗费用又远远低于欧美国家，是我们做试管的首选地。但切记要选择正规的医院，不要去一些小诊所，弃婴的华裔夫妇就是因为医疗条件没有得到保障，造成了全家的痛苦，而这一切明明是可以避免的。

随着去泰国的患者越来越多，国内很多服务机构应运而，如果想要简单方便不操心可以选择相应的服务机构，签证、预约、接机、翻译都可以提供服务，但是在选择上要十分小心，选择正规医院授权的正规机构，避免上当受骗。

分享这边文章，希望可以帮助想要去泰国做试管的家庭，能够清晰的了解到去泰国试管的过程，也祝愿想要做试管的家庭早日好孕，拥有自己可爱的宝宝。
