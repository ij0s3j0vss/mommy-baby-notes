# 怀孕的人血压会升高吗

> 更新时间：2026-09-11 (UTC+8)

孕妇高血压被称为妊娠期高血压疾病。妊娠期高血压疾病会危及母亲和婴儿的安全，严重还有可能危害胎儿生命，如胎儿窘迫。这些都容易导致儿童生长缓慢、缺氧等，需要及时治疗。

怀孕期间出现高血压在孕妇中常见，其危害不容忽视。妊娠高血压是产科特有的常见病。这种疾病发生在怀孕20周后，症状有头晕，胸闷，血压高，蛋白尿，上腹部不适，甚至痉挛和昏迷。注意血压的变化，并酌情服用口服药物。建议病人保持愉快的心情，调整日常饮食，避免吃过多咸的食物。按时到医院做产前检查，如果有任何异常情况，请及时去医院。

**1 .轻度妊娠高血压**

在这个阶段，孕妇的主要临床表现是血压轻微升高到140 / 90毫微克，伴有轻微的蛋白尿和/或水肿，体重异常增加。水肿通常从脚踝开始，逐渐延伸到小腿、大腿、外阴和腹部。抑郁性水肿被称为凹陷性水肿。它通常持续几天到几周，或者在清晨逐渐变得很早，或者迅速恶化。

**2 .中度妊娠高血压**

在这个阶段，孕妇的血压明显高于150 / 100毫微克，但不超过160 / 110毫微克。

**3 .重度妊娠高血压**

此时，母亲的病情进一步恶化，血压高达160 / 110毫微克或更高；24小时尿液中的蛋白质含量超过0.5g可能有不同程度的水肿，一系列有意识的症状出现在井中。这一阶段可分为先兆子痫和子痫。
