# 霉菌性阴道炎的多吃什么

> 更新时间：2026-09-15 (UTC+8)

霉菌性阴道炎患者可多吃富含维生素的食物、富含蛋白质的食物、具有抗菌消炎作用的食物、富含益生菌的食物、具有抗氧化作用的食物等。

1. 富含维生素的食物：维生素对于维持身体正常生理功能至关重要，能增强机体免疫力，有助于霉菌性阴道炎的恢复。像新鲜的蔬菜和水果，如苹果、橙子、菠菜、西兰花等，都富含各类维生素。苹果含有丰富的维生素 C 和纤维素，能促进肠道蠕动，增强抵抗力；橙子富含大量维生素 C，有抗氧化功效；菠菜含有多种维生素和矿物质，对身体有益；西兰花的维生素含量也很高，能提升身体的免疫能力。

2. 富含蛋白质的食物：蛋白质是身体细胞的重要组成部分，补充足够的蛋白质可以增强体质，提高对抗病菌的能力。常见的有瘦肉、鱼类、蛋类、豆类及豆制品等。瘦肉富含优质蛋白质和铁等营养成分；鱼类的蛋白质易于消化吸收，且含有对身体有益的不饱和脂肪酸；蛋类是优质蛋白质的良好来源；豆类及豆制品含有丰富的植物蛋白，如豆腐、豆浆等。

3. 具有抗菌消炎作用的食物：这类食物能在一定程度上抑制病菌生长，缓解炎症。例如大蒜，含有大蒜素，具有抗菌消炎的特性，可抑制霉菌等病菌；马齿苋有清热解毒、消炎杀菌的作用，对霉菌性阴道炎有辅助治疗效果；绿茶含有茶多酚等成分，也具备一定的抗菌消炎功效。

4. 富含益生菌的食物：适当摄入富含益生菌的食物有助于调节阴道内的菌群平衡，抑制有害菌的生长。常见的有酸奶，酸奶中含有大量的活性益生菌，能够帮助维持阴道微生态的稳定，增强阴道的自净能力，从而预防和改善霉菌性阴道炎。

5. 具有抗氧化作用的食物：抗氧化食物能帮助清除体内自由基，增强身体的抗氧化防御系统，提升整体健康水平。比如蓝莓，富含抗氧化物质花青素，抗氧化能力强；黑枸杞的抗氧化成分也很丰富，能有效保护细胞免受自由基的损伤；紫薯含有多种抗氧化物质，对身体有诸多益处。

在日常饮食中，要注意饮食均衡，避免食用辛辣、油腻、甜食等刺激性食物，这些食物可能会加重体内湿热，不利于病情恢复。同时，要养成良好的饮食习惯，规律进餐，保证充足的营养摄入，以促进身体尽快康复。
